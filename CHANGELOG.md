# Changelog

## 0.1.0 — 2026-10-23

- First pass. Offline console for the Forge system: summary cards, the build
  queue with dependencies and status, the kit graph, and the repo fleet.
- Engine `docs/play/forge.js` (zero dependencies): `statusOf`, `isRunnable`,
  `nextRunnable`, `summarize`, row builders, `search`, `toCSV` — shared by the
  browser and the headless tests.
- Single-page app (`docs/play/index.html`) on web-kit: search, CSV export,
  EN/HI/GU, theme, a11y.
- Bundled, read-only snapshot `docs/play/data.js`, regenerated by
  `scripts/gen_data.py` from `forge` + `registry`.
- Headless tests: 30 passed, 0 failed.
- Build workflow for the portable EXE and Android APK.
